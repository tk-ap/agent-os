# ASHWOOD Phase 2 Reference Pilot

This directory records one bounded Agent OS control-plane run against the ASHWOOD mobile capability-map layout issue.

The pilot proves the resolution chain manually before any orchestration runtime exists:

request → task → product/context → authorization → agent/skills → harness/host → branch → implementation → preview → PR → evidence

The product-side change lives in `tk-ap/tk-ap.github.io` on branch `fix/mobile-capability-map-layout` and draft PR #14. Merge and production remain human-gated.

The pilot is intentionally not autonomous. It records the decisions and evidence needed to evaluate whether the Phase 1 contracts are sufficient before building a router or executor.
