# Ecosystem Cross-Market Policy

Cross-marketing is a contextual continuation of user value, not a requirement to advertise every ecosystem product.

## Eligibility test

A cross-product recommendation is allowed only when all are true:

1. The current product has delivered its core value moment.
2. The adjacent product solves the user's next visible problem.
3. Relevant state can carry forward or the recommendation explains exactly what will not carry forward.
4. The benefit is explainable in one sentence.
5. Declining does not block the current product.

## Preferred moments

- ALVIRA profile ready -> Bridge: use this context in existing AI tools.
- Bridge connected -> Agent OS / Workflow Studio: give a coordinated workforce selected context.
- Ailhat P1 initiative approved -> Agent OS: assemble a workforce and execution plan.
- Agent OS plan ready -> Ledgato: verify effective authority before action.
- Ledgato authorizes work -> agentic harness: execute through the best available substrate.
- Harness execution complete -> Ailhat: measure whether the portfolio outcome improved.

## Prohibited patterns

- Generic ecosystem banners without user relevance.
- Blocking a completed workflow with an unrelated product pitch.
- Claiming an integration exists before the contract and implementation are verified.
- Sending users to another product before the current product delivers value.
- Copying an adjacent product's core capability to avoid a handoff.
